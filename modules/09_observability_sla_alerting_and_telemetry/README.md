# Module 09: Data Observability Pillars & OpenLineage Telemetry

## 1. The Five Observability Pillars
1. **Freshness**: Is the data up-to-date according to consumer SLAs?
2. **Volume**: Did the expected number of records arrive?
3. **Schema**: Have column names, types, or nullability changed unexpectedly?
4. **Quality**: Do values conform to business constraints and statistical distributions?
5. **Lineage**: Which downstream dashboards and machine learning models are impacted?
